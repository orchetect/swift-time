# SwiftTime

[![](https://img.shields.io/endpoint?url=https%3A%2F%2Fswiftpackageindex.com%2Fapi%2Fpackages%2Forchetect%2Fswift-time%2Fbadge%3Ftype%3Dplatforms)](https://swiftpackageindex.com/orchetect/swift-time) [![](https://img.shields.io/endpoint?url=https%3A%2F%2Fswiftpackageindex.com%2Fapi%2Fpackages%2Forchetect%2Fswift-time%2Fbadge%3Ftype%3Dswift-versions)](https://swiftpackageindex.com/orchetect/swift-time) [![License: MIT](http://img.shields.io/badge/License-MIT-lightgrey.svg?style=flat)](https://github.com/orchetect/swift-time/blob/main/LICENSE)

Provides the `Time` type for Swift.

This type is designed to help facilitate working with time durations and formatting time stamp strings.

## Getting Started

This library is available as a Swift Package Manager (SPM) package.

1. Add the **swift-time** repo as a dependency.

   ```swift
   .package(url: "https://github.com/orchetect/swift-time", from: "1.0.0")
   ```

2. Add **SwiftTime** to your target.

   ```swift
   .product(name: "SwiftTime", package: "swift-time")
   ```

3. Import **SwiftTime** to use it.

   ```swift
   import SwiftTime
   ```
